# Kindergarten B Mathematics Curriculum Matrix

## Purpose

This is the initial curriculum map for the local-first Kids Learning App. It is an original product design informed by common kindergarten mathematical skill patterns. It is not an official curriculum or competition syllabus.

| Level | Domain | Skill | Primary format | Difficulty |
|---:|---|---|---|---:|
| 1 | Number | Counting 1–5 | Visual counting | 1 |
| 2 | Number | Counting 1–10, comparison | Visual groups | 2 |
| 3 | Arithmetic | Addition within 5 | Visual addition | 3 |
| 4 | Arithmetic | Addition/subtraction within 10 | Visual groups | 4 |
| 5 | Number | Missing number | Choice | 5 |
| 6 | Pattern | Repeating visual patterns | Visual pattern | 6 |
| 7 | Number | Simple sequences | Choice | 7 |
| 8 | Geometry | Shape counting and comparison | Visual choice | 8 |
| 9 | Reasoning | Balance and number composition | Visual reasoning | 9 |
| 10 | Reasoning | Multi-step visual reasoning | Choice | 10 |

## Content Generation Rule

Competition and worksheet materials may be used only as references for concepts, skill coverage, difficulty progression, and question patterns. Questions, wording, illustrations, and copyrighted question sets must be newly generated for this application.
